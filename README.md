# 請求書作成システム

Vue.js + TypeScript で構築された請求書作成・PDF出力システムです。

## 概要

請求書を簡単に作成し、PDFとして出力できるWebアプリケーションです。
Excelで作成していた請求書作業をシステム化し、効率的な請求書管理を実現します。

## 機能

- 📝 請求書情報の入力
  - 請求書番号、請求日、支払期限
  - 請求先情報（会社名、住所、電話番号）
  - 請求元情報（会社名、住所、電話番号、メールアドレス）
- 📊 明細管理
  - 品名、数量、単価の入力
  - 複数明細の追加・削除
  - 金額の自動計算
- 💰 金額計算
  - 小計の自動計算
  - 消費税率の設定（デフォルト10%）
  - 消費税額の自動計算
  - 合計金額の表示
- 📄 PDF出力
  - ワンクリックでPDF生成
  - 請求書番号と日付を含むファイル名で保存
- 📱 レスポンシブデザイン
  - スマートフォンやタブレットでも利用可能

## 技術スタック

- **フロントエンド**: Vue 3 + TypeScript
- **ビルドツール**: Vite
- **PDF生成**: jsPDF
- **スタイリング**: CSS (Scoped Styles)

## セットアップ

### 必要な環境

- Node.js 20.x 以上
- npm 10.x 以上

### インストール

```bash
# 依存関係のインストール
npm install
```

## 使い方

### 開発サーバーの起動

```bash
npm run dev
```

ブラウザで http://localhost:5173/ にアクセスします。

### ビルド

```bash
npm run build
```

ビルドされたファイルは `dist/` ディレクトリに出力されます。

### プレビュー

```bash
npm run preview
```

ビルドされたアプリケーションをプレビューできます。

## 使用方法

1. **基本情報の入力**: 請求書番号、請求日、支払期限を入力します
2. **請求先情報の入力**: お客様の会社名、住所、電話番号を入力します
3. **請求元情報の入力**: あなたの会社の情報を入力します
4. **明細の入力**: 品名、数量、単価を入力します
   - 「+ 明細を追加」ボタンで明細を追加できます
   - 不要な明細は「削除」ボタンで削除できます
5. **金額の確認**: 小計、消費税、合計金額が自動計算されます
6. **備考の入力**: 必要に応じて備考を入力します
7. **PDF生成**: 「PDFを生成」ボタンをクリックしてPDFをダウンロードします
