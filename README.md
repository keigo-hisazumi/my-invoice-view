# 請求書作成システム

Vue.js + TypeScript で構築された請求書作成・管理システムです。

## 概要

請求書を簡単に作成・管理できるWebアプリケーションです。
Excelで作成していた請求書作業をシステム化し、効率的な請求書管理を実現します。
PDF出力はAPI側で行います。

## 機能

- 📋 請求書一覧
  - 作成済み請求書の一覧表示
  - 請求書番号、請求日、顧客名、金額の表示
  - 詳細表示、編集、削除機能
- ➕ 請求書作成
  - 請求書番号、請求日、支払期限の入力
  - 請求先情報（会社名、住所、電話番号）の入力
  - 請求元情報（会社名、住所、電話番号、メールアドレス）の入力
- 📊 明細管理
  - 品名、数量、単価の入力
  - 複数明細の追加・削除
  - 金額の自動計算
- 💰 金額計算
  - 小計の自動計算
  - 消費税率の設定（デフォルト10%）
  - 消費税額の自動計算
  - 合計金額の表示
- 💾 データ保存
  - ローカルストレージへの保存
  - 作成日時の自動記録
- 🔄 画面遷移
  - 一覧画面 ⇔ 作成画面の遷移
  - 「一覧に戻る」ボタン
- 📱 レスポンシブデザイン
  - スマートフォンやタブレットでも利用可能

## 技術スタック

- **フロントエンド**: Vue 3 + TypeScript
- **ルーティング**: Vue Router 4
- **ビルドツール**: Vite
- **スタイリング**: CSS (Scoped Styles)

## セットアップ

### 必要な環境

- Node.js 20.x 以上
- npm 10.x 以上

### インストール

```bash
# 依存関係のインストール
npm install
```

### 開発サーバーの起動


### ビルド

```bash
npm run build
```

ビルドされたファイルは `dist/` ディレクトリに出力されます。

### プレビュー

```bash
npm run preview
```

ビルドされたアプリケーションをプレビューできます。

## 使用方法

### 請求書一覧画面（トップページ）

1. アプリケーション起動時に請求書一覧が表示されます
2. **新規作成**: 「+ 新規作成」ボタンをクリックして請求書作成画面へ遷移
3. **詳細表示**: 「詳細」ボタンで請求書の詳細を表示
4. **編集**: 「編集」ボタンで既存の請求書を編集
5. **削除**: 「削除」ボタンで請求書を削除（確認ダイアログが表示されます）

### 請求書作成画面

1. **基本情報の入力**: 請求書番号、請求日、支払期限を入力
2. **請求先情報の入力**: お客様の会社名、住所、電話番号を入力
3. **請求元情報の入力**: あなたの会社の情報を入力
4. **明細の入力**: 品名、数量、単価を入力
   - 「+ 明細を追加」ボタンで明細を追加
   - 不要な明細は「削除」ボタンで削除
5. **金額の確認**: 小計、消費税、合計金額が自動計算されます
6. **備考の入力**: 必要に応じて備考を入力
7. **保存**: 「保存」ボタンをクリックして請求書を保存
8. **一覧に戻る**: 「← 一覧に戻る」ボタンで一覧画面に戻る
